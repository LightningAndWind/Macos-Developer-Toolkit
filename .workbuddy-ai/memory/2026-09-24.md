## 自绘滚动指示条抽为通用组件，补到 SSH/SFTP 文件列表
- 背景：原生滚动条在系统「始终显示滚动条」下有白色不透明轨道，此前 SSH/SFTP 列表直接 `.scrollIndicators(.never)` 去掉了滚动条。
- 改动：
  - 新建 `devkit/devkit/Core/DesignSystem/ScrollIndicator.swift`：从 TabBarView 抽出 `ScrollInfo` + `ScrollIndicator`（internal），加 `.scrollIndicatorBar()` ViewModifier（onScrollGeometryChange + trailing overlay）。
  - `TabBarView.swift` 改用共享组件，删除本地私有副本。
  - `SFTPSidePanelView.fileList`（SFTP 文件列表）与 `SSHStartupChooser.browser`（SSH 连接树，SSH 页面唯一的列表）加 `.scrollIndicators(.never)` + `.scrollIndicatorBar()`。
- 工程 objectVersion 77（PBXFileSystemSynchronizedRootGroup），新文件自动纳入构建，无需改 pbxproj。
- 验证：xcodebuild Debug ** BUILD SUCCEEDED **（按 local-swift-xcode-build skill 的宏进程内加载方案）。
